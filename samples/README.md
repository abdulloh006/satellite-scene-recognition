| file | scene |
|---|---|
| `eurosat_industrial.png` | Industrial |
| `eurosat_cropland.png` | Annual / permanent crop fields |
| `eurosat_river.png` | River |
| `eurosat_vegetation.png` | Pasture / herbaceous vegetation |
| `eurosat_highway.png` | Highway |

Add your own images here too, e.g. a phone photo for Week 1, or a Google Maps
